Summary

The week since v1.3 (Aug 17) brought no new models but a steady stream of new settings, environment variables, and default behaviors across CLI v2.1.234–v2.1.241[8]. The headline additions are two ways to shape a session before it starts: ANTHROPIC_DEFAULT_MODEL, which sets the model new sessions open on but yields to a /model pick and to a model key in your files[3][9], and a built-in "Concise" output style that leads with results and skips preamble[4]. Claude Code now continues your session automatically when a claude.ai usage limit resets (toggleable in /config)[1], gained a spellcheck setting for the prompt[2] and a keybindingFlavor: "readline" option for Bash-style word keys[5][6]. Plugin-marketplace maintainers get a headersHelper hook that mints short-lived auth headers[5], Windows finally gets cross-session messaging[6], and self-hosted runners gain graceful-drain and egress-proxy flags[5]. The current CLI is v2.1.241 (Aug 23); v2.1.240 and v2.1.241 are bug-fix-only releases[7]. Every claim below is cited; sources are listed at the bottom.

What's New

Highlights from Claude Code CLI v2.1.234 → v2.1.241 (August 17–23, 2026)[8].

  • ANTHROPIC_DEFAULT_MODEL sets the starting model, softly (v2.1.236, Aug 19). Unlike ANTHROPIC_MODEL, this new environment variable only sets the model new sessions start on: a /model pick still overrides it and persists across restarts, and per the settings docs it applies only when no settings file sets a model key[3][9].
  • Built-in "Concise" output style (v2.1.237, Aug 20). A new output style in which Claude leads with results and skips preamble and narration while doing the work just as thoroughly; select it under Output style in /config[4].
  • Auto-continue when your usage limit resets (v2.1.234, Aug 17). Claude Code now continues your session automatically when a claude.ai usage limit resets; turn it off in /config ("Continue automatically at usage limit")[1].
  • spellcheck setting (v2.1.235, Aug 18). An optional setting that underlines misspelled words in the prompt as you type, using an installed aspell, hunspell, or ispell[2].
  • keybindingFlavor: "readline" (v2.1.238–v2.1.239, Aug 20–21). Set this to make Ctrl+W delete back to the previous whitespace as in Bash; the default ("classic") is unchanged[5]. v2.1.239 extended it to word keys—Alt+F and Ctrl/Option+→ stop at the end of a word, Alt+D deletes to it, and punctuation separates words[6].
  • Plugin-marketplace headersHelper (v2.1.238, Aug 20). A headersHelper on a url marketplace or a catalog entry runs a command that mints HTTP headers (for example, a short-lived token) for catalog and same-origin archive fetches. A catalog entry's helper runs only when you install or update that plugin, after its command is shown, and claude plugin install/update ask [y/N] (or pass -y)[5]. Project-scoped .mcp.json helpers now require the folder's trust dialog and run without inherited credential env vars[5].
  • Windows cross-session messaging (v2.1.239, Aug 21). Claude Code sessions across your machines can now message each other with SendMessage and find each other with ListAgents on Windows, as on macOS and Linux[6]. Also new for peers: notify_when_idle on cross-session SendMessage asks another local session to send one notice when it next goes idle—opt-in, one-shot, no polling (macOS/Linux, v2.1.236)[3], and ListAgents now tells a session its own name and lists live teammates[6].
  • Self-hosted runner drain and proxy flags (v2.1.238, Aug 20). claude self-hosted-runner --defer-shutdown-max-min <minutes> keeps serving attached sessions on SIGTERM, parks the rest after that many minutes, then exits; and --proxy-authorization-command / --proxy-authorization-file supply a freshly issued Proxy-Authorization header for egress proxies that require one on every connection[5].
  • Auto mode reaches parity on cloud providers (v2.1.236, Aug 19). On Bedrock, Vertex AI, and Foundry, and when telemetry is disabled, the auto-mode classifier now uses the same defaults as on the Claude API, including severity-scored classification; Monitor allow rules are set aside while auto mode is active so Monitor commands are reviewed like Bash; and the git-status check can no longer be fooled by status.showUntrackedFiles=no into reporting a clean tree[3].
  • CLAUDE_CODE_PROJECT_DIR_NAME and a GitLab MR badge (v2.1.234, Aug 17). Hosts that give each session its own config directory can set a short name for the per-project transcript directory via CLAUDE_CODE_PROJECT_DIR_NAME; and repos with a GitLab remote and an authenticated glab CLI now show a merge-request badge (MR !N with draft/pending/green states) in the footer and statusline[1].
  • "Default teammate model" removed from /config (v2.1.234, Aug 17). Agent-team teammates now use the leader's model unless the spawn names one explicitly[1].
  • Dialogs open mid-turn; task notices go in <system-reminder> (v2.1.234, Aug 17). /permissions and /add-dir can now be used while Claude is working (rule changes apply to the rest of the turn), and several dialogs (/autocompact, /theme, /help, /config, /advisor) open mid-turn in the fullscreen TUI. Background-task notifications delivered between turns are now wrapped in <system-reminder> tags, matching mid-turn delivery[1].
  • Cost, usage, and provider surface changes (v2.1.236, v2.1.239). /usage now shows a usage-credits spend row for Team and Enterprise members[3]; cost estimates (/cost, status line, --max-budget-usd) now include the 1.1× US-only-inference premium for data-residency workspaces; and the one-time fullscreen-renderer offer now reaches Bedrock, Vertex, Foundry and other previously excluded setups, where new installs now start in fullscreen[6].
  • Security hardening (v2.1.234, v2.1.236). Remote file reads, session restore, CLAUDE.md includes, workflow scripts, and file uploads now reject Windows NT-namespace (\??\) paths, closing the remaining pre-approval file-access route in the NTLM credential-leak vector[1]. On macOS, wildcard read-deny rules (e.g. **/.env) now take precedence inside allowed read regions, cover matched directories' contents, and can't be bypassed by renaming the denied file[3].
  • Slash-command and skill refinements (v2.1.234, v2.1.236, v2.1.239). Pressing Enter on a slash-command typo or a command unavailable in the session now reports it instead of running the closest fuzzy match (prefixes and aliases still run)[3]; the built-in claude-api skill's context cost dropped from ~200k+ tokens to ~25k by loading reference docs on demand[1], and /claude-api upgrade now migrates Python projects from anthropic 0.x to 1.x[6]. Cloud-synced plugins now appear as name@synced and never override a same-named plugin you installed yourself[6].
  • v2.1.240 and v2.1.241 are bug-fix / reliability releases (Aug 22–23) with no new features, flags, or defaults[7].

Tips & Techniques

  • Pin a starting model without clobbering per-session picks. Export ANTHROPIC_DEFAULT_MODEL in your shell profile to choose which model new sessions open on. It's the soft counterpart to ANTHROPIC_MODEL: a /model switch still wins and persists, and a model key in a settings file takes precedence over the variable (v2.1.236)[3][9].
  • Switch to the "Concise" output style for routine work. When you want results-first replies without preamble, pick Concise under Output style in /config; it keeps the work thorough while trimming narration (v2.1.237)[4].
  • Get a one-shot idle ping instead of polling a peer session. On macOS/Linux, add notify_when_idle to a cross-session SendMessage to have another local Claude Code session send a single notice the next time it goes idle (v2.1.236)[3].
  • Adjust permissions and add directories without breaking your flow. /permissions and /add-dir can now be opened while Claude is working; permission-rule changes apply to the rest of the current turn (v2.1.234)[1].
  • Turn on Bash-style prompt editing if that's your muscle memory. Set keybindingFlavor: "readline" so Ctrl+W, Alt+F, Alt+D and Ctrl/Option+→ behave as they do in Bash; the default stays "classic" (v2.1.238–v2.1.239)[5][6].
  • Catch prompt typos before you send. Enable the spellcheck setting to underline misspelled words inline, backed by your installed aspell/hunspell/ispell (v2.1.235)[2].

The closest thing to a "trick" this period is official but worth flagging: because ANTHROPIC_DEFAULT_MODEL is soft (a settings-file model key and a live /model pick both beat it), you can set it per-machine or per-shell for a sensible starting default while leaving individual projects and sessions free to override—something ANTHROPIC_MODEL can't do because it wins over file-set models[3][9].

Recommended Default-Config Changes

  • Consider a soft default model per environment. Use ANTHROPIC_DEFAULT_MODEL (env) rather than ANTHROPIC_MODEL when you want a starting model that a project's model key or a /model pick can still override[3][9].
  • Prompt-quality settings. In settings.json, add "spellcheck": true if you have a spell checker installed, and set "keybindingFlavor": "readline" if you prefer Bash word-editing keys (default is "classic")[2][5].
  • Pick an output style deliberately. If your team values terse, results-first replies, standardize on the new Concise output style via /config (v2.1.237)[4].
  • Decide on auto-continue at usage limit. It's on by default—leave it if you want sessions to resume when your limit resets, or turn off "Continue automatically at usage limit" in /config if you'd rather they pause[1].
  • Team/Enterprise self-hosted runners. Use --defer-shutdown-max-min for graceful drain on SIGTERM, and --proxy-authorization-command/--proxy-authorization-file if your egress proxy needs a fresh Proxy-Authorization header per connection (v2.1.238)[5].
  • Plugin-marketplace maintainers. Serve private catalogs and archives with a headersHelper for short-lived token auth, and remember that catalog-entry helpers run on install/update behind a [y/N] prompt and that project-scoped helpers require the folder's trust dialog (v2.1.238)[5].
  • Team model defaults. With "Default teammate model" gone, agent-team teammates inherit the leader's model—name a model in the spawn when a teammate should use a different one (v2.1.234)[1].

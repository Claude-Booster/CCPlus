Summary

The week since v1.4 (Aug 24) brought a model-default change and a substantial security batch across CLI v2.1.245–v2.1.251[6]. The headline default change: seat-based Enterprise subscriptions now default to Opus 5, matching the other premium plans[4]. Two new PreModelSwitch / PostModelSwitch hook events let you block, confirm, or annotate a model change, and SessionStart resume hooks now receive session staleness and the estimated re-cache cost[4][7]. A new locked-down --restricted mode (also CLAUDE_CODE_RESTRICTED=1) strips the tools that run commands or code plus WebFetch, keeps file tools inside the working directory, refuses bypassPermissions, and ignores your settings files[3]. Agents gained a per-agent experimental.cacheTtl frontmatter key, and CLAUDE_CODE_SUBAGENT_MODEL was softened to a default that a per-agent or per-spawn model can override[3][4]. Rounding out the period: a new SendFeedback tool with a feedbackDrafts setting[2], an Auto-mode tab in /permissions[1], prompt-cache and spend-limit surfacing in /cost and /usage[4], and a wide file-access / sandbox hardening pass[4]. The current CLI is v2.1.251 (Aug 28); v2.1.245 and v2.1.250 are bug-fix / reliability releases[5]. Every claim below is cited; sources are listed at the bottom.

What's New

Highlights from Claude Code CLI v2.1.245 → v2.1.251 (August 25–28, 2026)[6].

  • Seat-based Enterprise now defaults to Opus 5 (v2.1.251, Aug 28). The default model for seat-based Enterprise subscriptions changed to Opus 5, matching the other premium plans[4]. No new model shipped this period — this is a default alignment, not a new release.
  • PreModelSwitch and PostModelSwitch hook events (v2.1.251, Aug 28). New hooks fire around a model change: PreModelSwitch runs before Claude Code applies a switch you or a client requested and can block it, while PostModelSwitch runs after the session's model changes (including changes Claude Code makes on its own, such as restoring the model on resume). Both match on the model's canonical name (e.g. claude-opus-5). SessionStart resume hooks now also receive session staleness and the estimated re-cache cost[4][7].
  • --restricted locked-down mode (v2.1.248, Aug 27). --restricted (or CLAUDE_CODE_RESTRICTED=1) removes the built-in tools that run commands or code and WebFetch (unless you name them in --tools), keeps file tools inside the working directory, refuses bypassPermissions, and ignores user, project, and local settings files[3].
  • Per-agent prompt-cache TTL (v2.1.248, Aug 27). Agent frontmatter now accepts experimental.cacheTtl ("5m" or "1h"), used as that agent's prompt-cache TTL when no subagent TTL setting is configured[3].
  • CLAUDE_CODE_SUBAGENT_MODEL is now a soft default (v2.1.251, Aug 28). It sets the default subagent model rather than overriding everything: an agent definition's model: and an explicit per-spawn model now take precedence over it[4].
  • SendFeedback tool and feedbackDrafts setting (v2.1.247, Aug 26). When something goes wrong in a session, Claude can draft a feedback report for you to review and send from /feedback; turn it off with the feedbackDrafts setting[2].
  • Auto-mode controls surface in /permissions (v2.1.246–v2.1.247, Aug 25–26). /permissions gained an Auto mode tab for viewing and editing the auto-mode classifier rules[1], and Bash permission prompts now show a tip pointing to auto mode with a one-keystroke "Yes, and switch to auto mode" option[2].
  • Prompt-cache and spend visibility (v2.1.251, Aug 28). /cost gained a per-session prompt-cache line (hit ratio, misses, tokens re-cached, warm/cold) plus a matching prompt_cache object for status-line scripts; and /usage gained a Spend limit bar with a rate_limits.spend_limit status-line field for developers behind a Claude apps gateway with spend limits[4].
  • claude attach <id> for background sessions (v2.1.251, Aug 28). attach, logs, stop, respawn, and rm are now listed in claude --help, and the --resume message for a running background session names the exact claude attach <id> command to use[4].
  • /effort is now per-model (v2.1.251, Aug 28). Your default effort level is saved per model, so each model keeps its own setting when you switch[4]. Relatedly, Opus 5 requests with effort xhigh/max and thinking turned off no longer fail with "effort … is not supported when thinking is disabled" — effort is sent as high in that case[4].
  • /claude-api cost-optimize and Admin API coverage (v2.1.247, Aug 26). A new /claude-api cost-optimize profiles an existing project's Claude API spend and works through cost levers (caching, token hygiene, batch, effort, model choice) one measured change at a time; the /claude-api skill also gained Admin API coverage (members, invites, workspaces, API keys, rate-limit reports, workload identity federation, CMEK)[2].
  • Broad file-access and sandbox hardening (v2.1.251, Aug 28). Several security fixes landed together: Read/Write/Edit no longer follow a symlink swapped inside the working directory after the permission check (a TOCTOU that could read or write outside the approved location); Grep and Glob now apply Read(...) deny rules to files reached through a symlinked search path; plugin commands can no longer point outside the plugin directory (rejected as path traversal); project settings can no longer enable detailed beta tracing or raw API-body logging; project-level .claude/settings.json env can no longer set CLAUDE_CONFIG_DIR, CLAUDE_CODE_TMPDIR, or TMPDIR/TMP/TEMP; and ANTHROPIC_CUSTOM_HEADERS from managed or project settings now requires approval when it sets a credential, org/tenant, routing, or API-behavior header[4]. Managed settings that terminate sandbox TLS, route sandbox traffic through your own proxy, inject credentials, or weaken sandbox isolation now require approval before they apply[4].
  • Enterprise /usage-credits and provider parity (v2.1.248, Aug 27). /usage-credits is now available for Enterprise organizations billed through AWS Marketplace, self-serve Enterprise, and Enterprise trials, so members can request a higher usage limit from their admin; cross-session messaging (SendMessage / ListAgents) now works between same-machine sessions on Bedrock, Vertex, and Foundry and when telemetry is disabled; and /loop's self-paced dynamic mode and no-prompt autonomous default are now always available, including on those providers[3].
  • Sonnet 5 auto-compacts later on the 1M window (v2.1.247, Aug 26). Sonnet 5's default auto-compact window was changed to its full 1M context, so 1M-window sessions now auto-compact at about 967K tokens instead of about 934K[2].
  • Smaller, quicker, and more streamable (v2.1.248, v2.1.251). The Workflow tool's description dropped from ~5.7k to ~1k tokens, with its script-writing reference moved into a bundled workflow-authoring skill[3]; the native binary is about 5 MB smaller and drops syntax highlighting for six rarely used languages (1c, gml, isbl, mathematica, maxima, sqf); and Remote Control clients now get live streaming of a foreground subagent's tool calls and results (background subagents still show status only)[4].
  • v2.1.245 and v2.1.250 are bug-fix / reliability releases (Aug 25, Aug 28). v2.1.245 fixes a startup crash on Linux distributions shipping glibc 2.44 (Arch, CachyOS, Fedora Rawhide); v2.1.250 is reliability improvements only[5].

Tips & Techniques

  • Gate model switches with a hook. Use the new PreModelSwitch event to block or confirm a switch away from your chosen model (match on the canonical model name), and PostModelSwitch to annotate or react after one — including switches Claude Code makes on its own, like restoring the model on resume (v2.1.251)[4][7].
  • Run untrusted or sensitive tasks in --restricted mode. Launch with claude --restricted (or CLAUDE_CODE_RESTRICTED=1) to drop command/code execution and WebFetch, keep file tools scoped to the working directory, and ignore settings files — a fast way to sandbox a review or read-only session (v2.1.248)[3].
  • Tune prompt caching per agent. Add experimental.cacheTtl: "1h" to a long-lived agent's frontmatter to hold its prompt cache longer when you have no global subagent TTL set (v2.1.248)[3].
  • Watch cache health from the status line. Read the new prompt_cache object (or the per-session line in /cost) to see hit ratio, misses, and re-cached tokens — useful for spotting cache-busting patterns (v2.1.251)[4].
  • Reattach to background work by name. When --resume reports a session is already running, use the exact claude attach <id> it prints instead of starting a second process (v2.1.251)[4].
  • Profile and trim API spend. Run /claude-api cost-optimize on a project to work through caching, token hygiene, batching, effort, and model choice one measured change at a time (v2.1.247)[2].
  • Edit auto-mode rules from /permissions. The new Auto-mode tab shows and lets you edit the classifier rules directly; a Bash permission prompt can also switch you into auto mode in one keystroke (v2.1.246–v2.1.247)[1][2].

The closest thing to a "trick" this period is official but underused: --restricted gives you a genuinely locked-down session in one flag — no shell, no code execution, no WebFetch, file tools confined to the working directory, and settings files ignored — which makes it a clean way to hand Claude a repo for read-only triage or to run an agent you don't fully trust, without hand-writing deny rules[3].

Recommended Default-Config Changes

  • Enterprise model default. Seat-based Enterprise subscriptions now start on Opus 5 by default; if you standardized on a specific model, confirm your org/user model settings still reflect what you want (v2.1.251)[4].
  • Add a model-switch guardrail. If your team must stay on a particular model, register a PreModelSwitch hook that blocks switches to anything else (v2.1.251)[4][7].
  • Reach for --restricted for review/CI sessions. Prefer --restricted (or CLAUDE_CODE_RESTRICTED=1) over hand-rolled deny lists when you want a session with no command/code execution and no WebFetch, file tools confined to the working directory, and settings files ignored (v2.1.248)[3].
  • Set subagent models where they belong. With CLAUDE_CODE_SUBAGENT_MODEL now a soft default, put a specific model in an agent's model: frontmatter (or pass it at spawn) when a subagent must use a particular model; the env var only fills the gap (v2.1.251)[4].
  • Per-agent cache TTL. Add experimental.cacheTtl to agent frontmatter for long-running agents instead of relying on a single global subagent TTL (v2.1.248)[3].
  • Decide on feedback drafts. The SendFeedback tool lets Claude draft a report when something breaks; leave it on for easy bug reports, or set feedbackDrafts off if you don't want it (v2.1.247)[2].
  • Move sensitive env out of project settings. Project-level .claude/settings.json env no longer sets CLAUDE_CONFIG_DIR, CLAUDE_CODE_TMPDIR, or TMPDIR/TMP/TEMP — set these in your shell, user, or managed settings instead (v2.1.251)[4].
  • Org spinner tips. Organizations can now rotate their own tips via spinnerTipsOverride ({id, text, cooldownSessions, priority} entries, tipsFile, and label) alongside the built-in ones (v2.1.247)[2].

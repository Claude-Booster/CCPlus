Summary

The stretch since v1.5 (Aug 31) is headlined by a new model: CLI v2.1.257 adds Claude Fable 5.1 (claude-fable-5-1), now the default Fable model — a 1M-context model at $10 / $50 per Mtok with cache reads at 2.5% of input (~$0.25 / Mtok)[1][7]. Around it came a wave of new settings, flags, and security defaults across v2.1.257–v2.1.261[6]: timeFormat / timeZone, an auto-mode Containment Escape rule that stops auto-approving cloud credential-metadata fetches and cross-tenant reach, CLAUDE_CODE_SUBAGENT_MODEL_FORCE, and permissions.blockReadsOutsideWorkingDirectories[1]. Orgs get a managedMcpServers managed setting and headless hosts get --permission-prompts none[2]. Fullscreen mode gains a /diff panel and /cost now explains why the prompt cache missed[3]. New this period too: /skill-doctor, bashOutputMaxChars / taskOutputMaxChars (up to 128K), and the retirement of keybindingFlavor — word-editing keys now always match Bash[4]. The current CLI is v2.1.263 (Sep 6); v2.1.252, v2.1.258, and v2.1.263 are bug-fix / reliability releases[5]. Every claim below is cited; sources are listed at the bottom.

What's New

Highlights from Claude Code CLI v2.1.252 → v2.1.263 (August 31 – September 6, 2026)[6].

  • Claude Fable 5.1 is the new default Fable model (v2.1.257, Sep 1). claude-fable-5-1 is a 1M-context model priced at $10 / input Mtok and $50 / output Mtok, with prompt-cache reads at 2.5% of input (~$0.25 / Mtok)[1]. Anthropic's model docs position it "for demanding reasoning and long-horizon agentic work," with adaptive thinking always on, a high default effort, and a June 2026 knowledge cutoff[7]. Note the rollout caveat: in Claude apps gateway sessions fable and best keep resolving to Fable 5 for now (gateways not yet configured for 5.1 reject it) — pick Fable 5.1 explicitly in /model to use it[1].
  • timeFormat and timeZone settings (v2.1.257, Sep 1). Choose 12-hour, 24-hour, 24-hour UTC, or a strftime pattern for the turn-end clock and transcript-view timestamps[1].
  • Auto mode gets a "Containment Escape" rule (v2.1.257, Sep 1). Cloud metadata-credential fetches, egress evasion, and cross-tenant reach are no longer auto-approved unless your environment marks them expected[1]. Relatedly, v2.1.261 makes auto mode treat a link that packs content into a public diagram renderer's URL as an upload to that site — no longer auto-approved unless you asked for it[4].
  • CLAUDE_CODE_SUBAGENT_MODEL_FORCE (v2.1.257, Sep 1). Applies CLAUDE_CODE_SUBAGENT_MODEL (or the main model) to every subagent, ignoring per-spawn and agent-definition model overrides[1] — the hard-override complement to v2.1.251's soft default.
  • Block reads outside the working directory (v2.1.257, Sep 1). Auto mode now shows a one-time prompt before the first file read outside the working directories, with an option to block such reads entirely via permissions.blockReadsOutsideWorkingDirectories[1].
  • managedMcpServers managed setting (v2.1.259, Sep 2). Organizations can push HTTP/SSE MCP servers to every user (same entry shape as .mcp.json); entries that name a local command to run are skipped[2]. Alongside it, allowedMcpServers now governs only servers users add, so a literal managed-mcp.json server it used to filter out will load on upgrade — use deniedMcpServers to keep one off[2].
  • --permission-prompts none for unattended hosts (v2.1.259, Sep 2). Anything that would prompt is denied automatically while the active permission mode (including auto mode) keeps deciding — a clean posture for headless CI[2]. claude plugin validate also gained --json for a machine-readable report[2].
  • /diff panel in fullscreen mode (v2.1.260, Sep 3). A diff panel opens beside the conversation and shows your uncommitted changes as Claude edits; toggle it with /diff[3].
  • /cost now explains cache misses (v2.1.260, Sep 3). A likely cause for a prompt-cache miss (e.g. tool definitions or system prompt changed, or idle past the TTL) is now surfaced in /cost and the status line's prompt_cache field[3].
  • /skill-doctor (v2.1.261, Sep 4). Shows which loaded skills go unused and what they cost in context, so you can prune them[4].
  • Bigger inline command/task output (v2.1.261, Sep 4). New bashOutputMaxChars and taskOutputMaxChars settings raise how much command and background-task output Claude receives inline before it is saved to a file — up to 128K characters[4]. --append-subagent-system-prompt-file reads the subagent system prompt from a file for prompts too large to pass on the command line[4].
  • keybindingFlavor is gone; word keys always match Bash (v2.1.261, Sep 4). The prompt's word-editing keys now behave like Bash — Ctrl+W deletes back to whitespace, Alt+F / Alt+D stop at word end, punctuation separates words — and keybindingFlavor no longer has any effect[4].
  • Auto-compact for 1M-context models (v2.1.260, Sep 3). Opus and Fable sessions now compact shortly before the 1M-token limit, and recovery compaction on very large contexts no longer times out at 10 minutes[3]. Text forms of /advisor (/advisor <model>, /advisor off) and /reload-plugins also came to headless (-p / Agent SDK) and desktop sessions[3].
  • Sandbox and settings hardening (v2.1.257–v2.1.261). Several safety-oriented defaults landed: defaultMode: "bypassPermissions" in project .claude/settings.json/settings.local.json is now ignored (set it in user or managed settings, or pass --permission-mode) and --add-dir refuses network paths like UNC shares (v2.1.257)[1]; a managed claudeMd no longer triggers the security-approval dialog, and ! bash-mode commands run outside the sandbox even under strict mode, like your own terminal (v2.1.260)[3]; the dangerous-rm prompt now also catches rm -rf on positional parameters and inside double-quoted sh -c scripts (v2.1.261)[4]; and managed settings that cannot be parsed now make Claude Code refuse to start and name the source, instead of silently going unenforced (v2.1.259)[2].
  • v2.1.252, v2.1.258, and v2.1.263 are bug-fix / reliability releases (Aug 31, Sep 1, Sep 6). v2.1.252 fixes Bash "task output swap refused" errors and "always allow" not saving in a project with no local settings file yet; v2.1.258 fixes a launch regression on macOS 12 (Monterey); v2.1.263 is bug fixes and reliability improvements[5]. (v2.1.253–254, v2.1.256, and v2.1.262 have no GitHub Release tags; v2.1.255 shipped briefly and introduced the macOS 12 launch regression that v2.1.258 then fixed.)

Tips & Techniques

  • Reach for Fable 5.1 on hard, long-horizon work. Anthropic positions claude-fable-5-1 for demanding reasoning and long-horizon agentic tasks; on a Claude apps gateway, pick it explicitly in /model since fable/best still resolve to Fable 5 until the gateway is configured for it (v2.1.257)[1][7].
  • Prune skills you don't use. Run /skill-doctor to see which loaded skills go unused and what they cost in context, then remove them to reclaim the window (v2.1.261)[4].
  • Watch edits land with /diff. In fullscreen mode, toggle the /diff panel to see uncommitted changes accumulate beside the conversation as Claude works (v2.1.260)[3].
  • Diagnose a cold cache. When costs spike, check /cost (or the prompt_cache status-line field) for the reason the cache missed — changed tool definitions, a changed system prompt, or an idle gap past the TTL (v2.1.260)[3].
  • Give commands room before they spill to a file. Raise bashOutputMaxChars / taskOutputMaxChars (up to 128K) so long build logs or test output stay inline for the model instead of being truncated to a file (v2.1.261)[4].
  • Lock every subagent to one model. Set CLAUDE_CODE_SUBAGENT_MODEL_FORCE when you need a subagent model applied everywhere, overriding per-agent and per-spawn choices — handy for cost control in CI (v2.1.257)[1].
  • Confine reads on a sensitive repo. Turn on permissions.blockReadsOutsideWorkingDirectories to keep file reads inside your working directories, and expect a one-time prompt the first time a read would step outside (v2.1.257)[1].
  • Set your clock. Use timeZone and timeFormat (12h / 24h / 24h-UTC / strftime) so the turn-end clock and transcript timestamps read the way you expect, especially across teammates in different zones (v2.1.257)[1].

Recommended Default-Config Changes

  • Decide your Fable default. Fable 5.1 is now the default Fable model; if you pin a Fable model via ANTHROPIC_DEFAULT_FABLE_MODEL or a gateway, confirm it resolves to the version you intend (gateways may still serve Fable 5 until configured for 5.1) (v2.1.257 / v2.1.260)[1][3][7].
  • Move bypassPermissions out of project settings. defaultMode: "bypassPermissions" in .claude/settings.json or settings.local.json is now ignored — set it in user or managed settings, or pass --permission-mode (v2.1.257)[1].
  • Drop keybindingFlavor. It no longer has any effect; word-editing keys always follow Bash now, so you can remove the setting (v2.1.261)[4].
  • Standardize org MCP via managedMcpServers. Push HTTP/SSE MCP servers to every user from managed settings instead of hand-adding them per machine; use deniedMcpServers to suppress any you don't want (v2.1.259)[2].
  • Set headless posture explicitly. For CI and other unattended hosts, add --permission-prompts none so nothing silently waits on a prompt (v2.1.259)[2].
  • Tune inline output caps. Add bashOutputMaxChars / taskOutputMaxChars (up to 128K) if your builds/tests routinely produce output the model should see in full (v2.1.261)[4].
  • Confine reads and set the clock. Consider permissions.blockReadsOutsideWorkingDirectories on sensitive repos, and set timeZone / timeFormat for consistent timestamps (v2.1.257)[1].
